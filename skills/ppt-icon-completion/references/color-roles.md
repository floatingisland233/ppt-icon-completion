# Color roles

Common enterprise-report roles (hex without `#`):

| Role | Typical use | Example |
|------|-------------|---------|
| header_navy | Top bar | `1A4A8C` |
| card_blue | 背景卡 | `2B6CB0` |
| card_green | 目标卡 | `2FA06E` |
| card_purple | 量化效益 | `7A5CA8` |
| card_teal | 非量化效益 | `2A9B8F` |
| process_blue | To-Be / chevron | `2F6FB8` |
| asis_gray | As-Is icons | `7A8A9A` |
| alert_red | Warning | `D94545` |
| white | On dark pills | `FFFFFF` |

Same `theme_color_role` ⇒ same fill across the row.
